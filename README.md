SPAM EMAILS


DATASET SUMMARY
The email spam dataset is a collection of email messages labeled as either spam or non-spam (ham). It includes the full text of each email along with its classification, it includes two columns: the email text and its spam classification. Each row represents a single email, with the text providing the full content and the label indicating whether it is spam (1) or not (0). 

MACHINE LEARNING PROBLEM
classification problem;  Binary label indicating whether the email is spam (1) or not (0).
